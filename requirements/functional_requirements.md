# Core Functional Requirements

## 66. UPDATED CORE FUNCTIONAL REQUIREMENTS
---

* **FR-01** Configure the AI API server URL.
* **FR-02** Connect to the configured AI API over the LAN.
* **FR-03** Retrieve available AI models.
* **FR-04** Retrieve currently loaded models.
* **FR-05** Retrieve model status.
* **FR-06** Retrieve model memory usage.
* **FR-07** Retrieve total AI server RAM usage.
* **FR-08** Allow the user to load a specific model.
* **FR-09** Allow the user to unload a specific model.
* **FR-10** Allow the user to unload all models.
* **FR-11** Allow the user to select the AI model for each message.
* **FR-12** Allow the user to change models during a conversation.
* **FR-13** Preserve conversation history when changing models.
* **FR-14** Support multiple models loaded simultaneously.
* **FR-15** Send text messages to the AI.
* **FR-16** Receive AI text responses.
* **FR-17** Stream AI responses when supported by the API.
* **FR-18** Render Markdown responses.
* **FR-19** Render LaTeX mathematical expressions.
* **FR-20** Render formatted source code.
* **FR-21** Allow PDF attachments.
* **FR-22** Allow image attachments.
* **FR-23** Include previous conversation context in subsequent requests.
* **FR-24** Include relevant files in the conversation context.
* **FR-25** Display AI reasoning/thinking when available.
* **FR-26** Display Time to First Token (TTFT).
* **FR-27** Display tokens per second.
* **FR-28** Display reasoning time.
* **FR-29** Display generation time.
* **FR-30** Display total response time.
* **FR-31** Display client RAM usage.
* **FR-32** Display AI server RAM usage.
* **FR-33** Display memory usage of each loaded model.
* **FR-34** Display total memory used by loaded models.
* **FR-35** Support LAN access from multiple client devices.
* **FR-36** Receive AI-generated files/images when supported.
* **FR-37** Create and maintain a persistent list of conversations.
* **FR-38** Display conversations in a sidebar.
* **FR-39** Search conversations from the sidebar.
* **FR-40** Search conversations by title.
* **FR-41** Search conversations by message content.
* **FR-42** Create new conversations.
* **FR-43** Open and restore previous conversations.
* **FR-44** Rename conversations.
* **FR-45** Move conversations to Trash.
* **FR-46** Confirm conversation deletion.
* **FR-47** Restore conversations from Trash.
* **FR-48** Permanently delete conversations with explicit confirmation.
* **FR-49** Persist conversations across browser refreshes and application restarts.
* **FR-50** Preserve conversation files and context.
* **FR-51** Provide responsive behavior for desktop, laptop, tablet, and mobile devices.
* **FR-52** Provide a collapsible/overlay sidebar on small screens.
* **FR-53** Provide a responsive chat input.
* **FR-54** Provide responsive model-management views.
* **FR-55** Provide responsive performance metrics.
* **FR-56** Provide a clean and lightweight local ChatGPT-like interface.
* **FR-57** Use a white/light visual theme.
* **FR-58** Export the selected conversation as a Markdown (`.md`) file while preserving conversation content and formatting.
